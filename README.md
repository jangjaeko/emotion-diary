# Emotion Diary (Vite + React)

A simple **Emotion Diary** web app built with **Vite + React**.  
This project is written in **JSX** and styled with **plain CSS** (no CSS framework).

I intentionally kept the setup minimal — I wanted to build something practical again without relying on many packages, and refresh core React fundamentals.

---

## Features

- Create a diary entry with an emotion (e.g., happy, sad, angry, etc.)
- View a list of diary entries
- Sort entries (latest / oldest)
- Edit and delete an entry
- Simple, clean UI with vanilla CSS

---

## Tech Stack

- **React**
- **Vite**
- **JavaScript (JSX)**
- **CSS (Vanilla CSS)**

No heavy UI libraries or state-management packages were used.
